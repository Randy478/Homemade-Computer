# Inter-Board Bus Pinout

60-pin bus on right-angle 2×30 pin headers (2.54mm pitch). Every edge connection between boards uses this pinout.

## Signal Groups

### Data Bus (D0–D31) — Pins 3–34
32-bit bidirectional data bus. Active during all memory and I/O cycles. directly from the 486's data pins (via 74HC245 buffers on the CPU board).

### Address Bus (A0–A15) — Pins 35–50
16 address lines on the inter-board bus. Enough to address 64KB of I/O space and serve as the row/column address for DRAM. Full 32-bit addressing is handled by the CPLD which decodes higher bits internally and generates per-board chip selects.

### Control Signals — Pins 51–58

| Signal | Dir | Description |
|--------|-----|-------------|
| /MEMR | Out | Memory Read strobe (active low) |
| /MEMW | Out | Memory Write strobe (active low) |
| /IOR | Out | I/O Read strobe (active low) |
| /IOW | Out | I/O Write strobe (active low) |
| /RESET | Out | System reset (active low) |
| CLK | Out | 33MHz system clock |
| /IRQ | In | Interrupt request (active low, directly from peripherals) |
| /DACK | Out | DMA acknowledge (active low, for FDC) |

### Power — Pins 1–2, 59–60
Two GND pins and two VCC (+5V) pins. Multiple power pins ensure adequate current delivery across the bus. Each board also has local decoupling capacitors.

## Notes

- Address bits A16–A31 are not on the main bus. The CPLD on Board 3 decodes the full 32-bit address from the CPU and generates chip select signals routed directly to specific boards.
- The ISA bus clock (8.33MHz) is generated by the CPLD and routed directly from Board 3 to Board 7 (ISA GPU), not through the main bus.
- All active-low signals are active-low per standard PC convention.
- Bus direction is relative to the CPU (Out = CPU drives, In = peripheral drives).
